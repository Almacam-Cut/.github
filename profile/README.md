## Four Beats

1. **Name the order.** Give the Almacam Cut shop order a short title before you mix a DXF pile.
2. **Pin the live parts.** Keep current shapes on Almacam Cut nest engine and leave unused plates aside.
3. **Read the technology.** Open Almacam Cut cutting technology before you move a nest that already has a plate.
4. **Check the layout.** Read Almacam Cut plate layout before you archive an order.
5. **Keep the name.** Leave the nest attached to the same Almacam Cut shop order.
6. **Close the loop.** Clear finished orders so the next Almacam Cut visit does not start with a search.

## First Questions

**Does Almacam Cut replace every other program?**
No. Almacam Cut sits beside the table list, browser, and files you already use.

**Can two people share one computer?**
Yes. Each person keeps a separate Almacam Cut profile.

**What should a new user try first?**
One small Almacam Cut nest today, then the same plate layout tomorrow.

**Does cutting technology leave the shop order?**
No. Almacam Cut cutting technology stays with Almacam Cut plate layout on that order.

**Is Almacam Cut only for a finished plate?**
No. Almacam Cut can hold a single nest while the rest of the shop stays off the board.

**Do mixed DXF piles stay named?**
Yes. A named Almacam Cut shop order keeps the nest readable before the table starts.

## Field Note

Almacam Cut is easier to trust when the shop order stays smaller than the folder it came from. A named order shows what is active, the nest pins show what you will cut today, and the closing note tells the next person which plate changed.

A review should not have to guess which DXF pile belongs to the open nest. Keep that pair together inside Almacam Cut.

## One Real Pass

Pick an order that already has a name. Open it in Almacam Cut, keep only those parts on the nest engine, and finish one plate layout you can see.

If the pass feels crowded, the set is too wide. Drop anything that belongs to a different order and leave it out of this Almacam Cut shop order.
